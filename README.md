# Brodie — Join a Team Prototype

Interactive prototype of the athlete "Join a Team" registration flow for join.brodierec.com.

Three flows fork from the landing page:
- **Full season** — register for the upcoming season on an Ambassador Team.
- **Drop-in** — hoop with an Ambassador Team in a single upcoming game (first game free).
- **Join a roster** — join an existing team with a captain's code.

Open the live link, or open `index.html` in any browser. Use the dev toolbar at the top to jump to any screen or state.
